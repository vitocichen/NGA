设置「强制更新」

强制更新需要一个 GitHub Token，只需要设置一次，保存在这台手机的浏览器里。

  1. 在 GitHub 打开 新建细粒度 Token
  2. Token name 随便填，Expiration 选一个较长的期限
  3. Repository access 选 Only select repositories → 选 NGA
  4. Permissions → Repository permissions → Actions 设为 Read and write，其他保持不动
  5. 点 Generate token，复制以 github_pat_ 开头的内容粘贴到下面

这个 Token 只能触发和查看本仓库的工作流，读不到 Cookie，也改不了代码。
